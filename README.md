# ICFT-Protocol
ICFT is a DeFi lending protocol enabling simple USDT-collateralized borrowing through the ICFT token.

ICFT allows users to deposit USDT as collateral and borrow ICFT tokens within predefined risk parameters.

## Core Mechanism

USDT Collateral
        ↓
Lending Pool
        ↓
ICFT Borrowing
        ↓
Interest
        ↓
Repayment
        ↓
Collateral Withdrawal

## MVP

- ICFT ERC-20 token
- Lending Pool
- USDT collateral
- LTV
- Interest calculation
- Borrow / Repay / Withdraw
- Liquidation mechanism
- ICFT/USDT price oracle
- Risk management parameters
- Emergency pause
- Basic frontend
- Wallet integration
- Testnet deployment
- Automated tests
